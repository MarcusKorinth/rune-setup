# @rune/cli

The `rune` command line is planned to provide `rune validate`, `rune run` (interactive or
`--non-interactive`), `rune schema` and `rune gui install` — see
[docs/architecture.md](../../docs/architecture.md) §4.1. When the CLI lands, install it with
`npm install -g @rune/cli` (Node 22 LTS).

Milestone 1 is in progress; the CLI package remains a skeleton until its commands land. See
[docs/roadmap.md](../../docs/roadmap.md).
