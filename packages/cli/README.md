# @rune/cli

The `rune` command line: `rune validate`, `rune run` (interactive or `--non-interactive`),
and `rune schema` — see [docs/architecture.md](../../docs/architecture.md) §4.1. Install
with `npm install -g @rune/cli` (Node 22 LTS). The Milestone 3 GUI commands `rune gui install`
and `rune run --gui` are planned, not currently implemented.

Milestones 0–2 / v0.1 core are implemented, including the interactive CLI and mode-parity
contract suite. See [docs/roadmap.md](../../docs/roadmap.md).
