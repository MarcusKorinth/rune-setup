# @rune/engine

The RUNE engine's Milestone 1 implementation includes manifest loading and validation,
five-layer value resolution, secret handling, static planning, a default process runner,
sequential execution, lifecycle events and versioned results. The `Session` facade and the CLI
and GUI integrations remain planned work. See [docs/architecture.md](../../docs/architecture.md).

Milestone 1 is in progress. See [docs/roadmap.md](../../docs/roadmap.md).
